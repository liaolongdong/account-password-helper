核心特性

为开发者和测试人员打造的轻量、安全、好用的密码管理工具

端到端本地加密

采用业界标准 AES-256 加密体系，敏感数据本地加密存储，永远不上传任何服务器。

智能识别登录表单

自动识别用户名、密码、手机号、验证码字段，并能自动勾选「记住密码」「同意条款」等选项。

一键智能填充

无论是 React、Vue 等现代框架还是传统页面，都能稳定填充；可选填充后自动触发登录。

CSV / JSON 批量导入导出

提供标准 CSV 模板，支持中英文列名；同时支持 JSON 格式导入导出；导出前自动验证主密码，方便备份与迁移。

侧边栏快速填充

登录页输入框获得焦点时，侧边栏自动展示匹配账号；点击即填充，效率倍增。

自动保存登录凭证

Chrome 式凭证捕获，登录时弹窗确认；弹窗中可编辑标签和备注；支持白名单/黑名单匹配、凭证指纹智能去重、「不再提示」一键屏蔽域名。

四步开始使用

无需注册，无需登录，下载即用

01

安装扩展

在 Chrome 浏览器中安装本扩展，安装完成后即可在工具栏看到钥匙图标。

02

设置主密码

首次使用设置一个至少 8 位、包含字母数字与特殊字符的主密码，作为唯一钥匙。

03

添加或导入密码

手动新增账号，或通过 CSV 模板、JSON 文件批量导入历史账号，标签分类一目了然。

04

享受自动填充

访问登录页面，点击侧边栏或悬浮按钮的对应账号，账号密码即刻填入。
