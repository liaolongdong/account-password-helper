ABOUT THE AUTHOR

About the author

liaolongdong (Better) is an open-source enthusiast and contributor maintaining free, local-first browser extensions in their spare time, with no fees and no monetization.

What I work on

My projects share one premise: the work should happen on the user's computer, rather than sending the data away first.

None of these projects carry ads or paid subscriptions; they are built and maintained in my spare time.

  • Local-first: compute and store on the machine whenever the job allows it.
  • Offline first: the network is used only where it is unavoidable, and every outbound request is documented.
  • Open and auditable: code, permissions and key design decisions are public, so security claims can be checked.
  • State the limits: these tools are not sold as a universal vault; supported scenarios and boundaries are written down.

Open-source projects

Account Password Helper

A local-first Chrome password manager: exact-host isolation for multi-environment accounts, one-click fill and login, built-in TOTP, and an offline security audit. The master password derives the key with PBKDF2-SHA256 (600,000 rounds), sensitive fields are encrypted individually with AES-256-GCM, and the data stays on your machine.

Product page GitHub Chrome Web Store Engineering blog

Transfer Any File

An offline converter for 14 file formats that uploads nothing: Markdown, Word, PDF, Excel, CSV, JSON, HTML and images, with mixed-format batches and multi-step chains, all in the browser.

Product page GitHub Chrome Web Store

Cross-origin Proxy

Proxies a page's API requests to another backend environment: rewrite URLs, headers and responses, mock conditionally, inject delays, block requests, retry failures and forward WebSocket — all configured in the browser.

Product page GitHub Chrome Web Store

Account Password Helper targets development, testing and everyday sign-in scenarios. Storing highly sensitive credentials such as banking or payment accounts in any browser extension is not recommended. A forgotten master password cannot be recovered — export encrypted backups regularly.
