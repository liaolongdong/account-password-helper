我在做什么

我的项目都围绕同一个判断：工具应该在用户的电脑上完成工作，而不是先把数据交出去。

这些项目不投放广告，也没有付费订阅；开发和维护都发生在业余时间。

  • 本地优先：能在本机算的就在本机算，能在本机存的就在本机存。
  • 能离线就不联网：网络只用于不得不联网的环节，每个外联都在文档里写明。
  • 开源可审计：代码、权限声明与关键设计公开，安全结论可以自己复核。
  • 说清边界：不把工具说成万能保险箱，适用场景与限制写在明面上。

开源项目

账号密码管理助手

本地优先的 Chrome 密码管理器：精确域名隔离多环境账号、一键填充与登录、内置 TOTP、离线安全体检。主密码经 PBKDF2-SHA256 60 万轮派生，敏感字段逐字段 AES-256-GCM 加密，数据只写本机。

产品页 GitHub Chrome 应用商店 技术博客

文件格式任意转换助手

14 种格式在浏览器里互转、一个字节也不上传的离线文件转换器：Markdown、Word、PDF、Excel、CSV、JSON、HTML 与图片，支持批量混合格式与多步链路。

产品页 GitHub Chrome 应用商店

跨域代理助手 · Cross-origin Proxy

把页面发出的 API 请求代理到另一个后端环境：重写 URL、请求头与响应，条件化 Mock、注入延迟、阻断请求、失败重试、转发 WebSocket，全部在浏览器里配置。

产品页 GitHub Chrome 应用商店

账号密码管理助手面向开发、测试与日常登录场景；不建议在任何浏览器扩展中存放银行、支付类高敏感凭证。主密码遗忘默认无法找回（事先登记过离线恢复密钥的除外），请定期导出加密备份。
