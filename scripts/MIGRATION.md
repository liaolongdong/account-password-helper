# 自动合并脚本迁移说明

## 从 Shell 版本迁移到 Node.js 版本

### 变更概述

我们已将自动合并脚本从 Shell 脚本 (`auto-merge-main.sh`) 迁移到 Node.js 脚本 (`auto-merge-main.js`)，并进行了以下优化：

### 主要改进

1. **智能推送逻辑**
   - ✅ 自动检测分支是否有对应的远程分支
   - ✅ 远程分支：合并成功后自动推送
   - ✅ 本地分支：仅执行合并，不推送

2. **更好的错误处理**
   - ✅ 工作区状态检查
   - ✅ 更详细的错误信息
   - ✅ 更清晰的输出格式

3. **跨平台兼容**
   - ✅ Node.js 版本在 Windows/macOS/Linux 上都能运行
   - ✅ 不再依赖 Bash 特定语法

4. **更详细的报告**
   - ✅ 区分已推送和仅本地合并的分支数量
   - ✅ 彩色输出更易读

### 使用方式变更

**之前（Shell 版本）**：

```bash
bash scripts/auto-merge-main.sh
```

**现在（Node.js 版本）**：

```bash
node scripts/auto-merge-main.js
```

### Git Hook 已自动更新

`.git/hooks/post-merge` 已更新为调用 Node.js 脚本，无需手动修改。

### 旧版本处理

Shell 脚本 `auto-merge-main.sh` 仍然保留在项目中作为备份，但已不再使用。您可以：

1. **保留**：作为参考和备份
2. **删除**：如果确认不再需要

### 环境要求

- Node.js（项目已具备，无需额外安装）

### 功能对比

| 功能         | Shell 版本  | Node.js 版本  |
| ------------ | ----------- | ------------- |
| 自动合并     | ✅          | ✅            |
| 自动推送     | ✅ 所有分支 | ✅ 仅远程分支 |
| 远程分支检测 | ❌          | ✅            |
| 工作区检查   | ❌          | ✅            |
| 彩色输出     | ✅          | ✅ 更丰富     |
| 错误报告     | 基础        | 详细          |
| 跨平台       | 仅 Unix     | 全平台        |

### 回滚方案

如果遇到问题，可以临时切换回 Shell 版本：

1. 编辑 `.git/hooks/post-merge`
2. 将 `auto-merge-main.js` 改为 `auto-merge-main.sh`
3. 将 `node` 改为 `bash`

但建议优先反馈问题，我们会及时修复。
