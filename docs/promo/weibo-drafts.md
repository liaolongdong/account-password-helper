## 方案 A：单条主推微博（配图 9 宫格 / GIF）

我做了一个「只在你浏览器里」的密码管理 Chrome 扩展，开源免费、数据 100% 本地：

🔑 Ctrl+Shift+F 一键登录：自动填充 + 勾协议 + 点登录，不只是填表
🎯 精确域名隔离 dev/test/staging/prod，多环境账号再也不填错（开发者刚需）
📱 内置 TOTP 两步验证，GitHub 式登录自动锚定活码，告别手机验证器
🛡 PBKDF2(60 万迭代)+AES-256-GCM 纯本地加密，零网络传输、免注册
🩺 离线安全体检：弱密码/复用/泄露/过期/未开 2FA 五维打分
📦 支持从 Chrome / LastPass / Bitwarden / 1Password 一键导入

不连云端、不要账号、不要订阅。缺点也很实在：没有云同步、没有手机端。

安装：Chrome 应用商店搜「账号密码管理助手」
官网演示：https://liaolongdong.github.io/account-password-helper/
开源：https://github.com/liaolongdong/account-password-helper
