## 正文

做开发久了，我发现一个特别真实的问题：**很多时间不是浪费在写代码上，而是浪费在"找账号"上。**

测试问我："管理员账号是多少？"
产品问我："有没有普通用户账号？"
联调、修 bug 时我自己也在翻账号备忘录——开发环境一套，测试环境一套，预发布又一套；同一个系统还要区分管理员、运营、审核员、普通用户。

账号越多越乱，复制粘贴越频繁，越容易选错环境。它看起来是小麻烦，但每天重复 N 次，真的很消耗耐心。

【配图：01-infographic-pain-points.png 开发测试的账号之痛】

## 我要的不是"密码保险箱"，是"开发测试账号工作台"

我也用过 Chrome 自带密码管理，用过 Excel、飞书文档、备忘录，也试过 1Password、Bitwarden。它们都能存账号，但解决不了开发测试场景里的几个问题：

- 同一个系统多个账号，Chrome 很难按环境、角色快速筛选，经常填错环境；
- 新项目交接，几十个账号手动录入，容易漏、容易错；
- Excel 和备忘录能看不能填，每次还得复制粘贴；
- 临时测试账号生命周期短，塞进重型密码管理器又显得太重。

所以我想要的不是一个"大而全"的密码保险箱，而是一个更贴近日常的小工具：**打开登录页，选账号，一键填充并自动登录。**

这就是「账号密码管理助手」（Account Password Helper）想解决的问题。它是一款**开源免费、纯本地加密**的 Chrome 扩展，为开发者和测试人员量身打造。

【配图：02-comparison-tools.png 三大工具对比】

> 一句话对比：Chrome 是"顺手存一下"，1Password 是"专业保险库"，而这个插件更像"开发测试账号工作台"。

## 它到底能干什么

**① 快捷键一键登录——不只是填充。**
按下 `Ctrl+Shift+F`，插件会帮你完成三件事：自动填充账号密码 → 自动勾选"已阅读并同意协议" → 自动点击登录按钮。别的工具只帮你填表单，登录按钮还得你自己点；这里是一步到位。

【配图：06-sidepanel-fill.png 侧边栏一键填充】

**② 多环境账号隔离——开发者刚需。**
精确域名匹配，把同一站点的 dev / test / staging / prod 账号彻底分开，绝不会出现"拿生产账号登进测试环境"的尴尬。本地开发（localhost）时默认展示全部账号，联调切换更省心。

**③ 内置两步验证（TOTP）——告别手机验证器。**
验证码和密码存在一起，按 RFC 6238 本地生成。登录 GitHub 这类两步验证站点时，插件会自动在验证码输入框旁锚定一个"活码胶囊"，一键填入，不用再掏手机。

【配图：09-totp-code.png TOTP 两步验证】

**④ 四种填充方式，怎么顺手怎么来。**
输入框钥匙图标的内联面板、侧边栏、输入框上**右键**填充、以及 `Ctrl+Shift+F` 快捷键——覆盖从"精确点选"到"闭眼一键"的所有习惯。

**⑤ 自动保存 + 批量导入迁移。**
登录时自动弹窗确认保存（智能去重、域名黑白名单）；支持从 Chrome / LastPass / Bitwarden / 1Password 一键导入，CSV/JSON 双格式，30 秒搬家。

**⑥ 离线安全体检。**
一键给密码库打 0–100 分，五维检测：弱密码 / 复用 / 常见泄露 / 长期未更新 / 未开两步验证——全程本地计算，不联网。

【配图：10-health-check.png 安全体检仪表盘】

除此之外还有：6 款主题、中英文双语界面、回收站 30 天、密码修改历史可回滚、剪贴板定时自动清除、大写锁定实时提示……细节都在这半年里被真实使用打磨过。

## 关于安全，说点实在的

- **数据只在你自己的浏览器里。** 主密码经 PBKDF2（60 万次迭代）派生密钥，敏感字段用 AES-256-GCM 加密存储，**零网络传输**，没有服务器、不用注册账号。
- **代码全公开。** 基于 **GPL-3.0** 开源，核心逻辑都能在 GitHub 上看到，不是黑盒。
- **技术栈**：WXT + Vue 3 + TypeScript + Element Plus，完全拥抱 Chrome Manifest V3，**632 项自动化测试**兜底。

> 温馨提示：它为开发、测试与日常登录场景而生。为保障资产安全，建议不要在任何浏览器扩展中存放银行、支付等高敏感凭证。

## 适合谁

如果你是开发，经常在本地/测试/预发之间切账号——它很适合你。
如果你是测试，经常验证不同角色权限、批量维护测试账号——它会非常省时间。
如果你是产品，经常拿演示账号、验收账号看功能——它能减少很多重复操作。

**只要你有多账号、多系统、多环境的登录场景，就用得上。**

## 怎么开始用

1. 安装（二选一）：
   - Chrome 应用商店搜索「账号密码管理助手」一键安装（自动更新）；
   - 无法访问 Google 的用户，从 GitHub Releases 下载 zip，开发者模式手动加载。
2. 设置一个主密码（至少 8 位，含字母+数字+特殊字符，**忘了找不回，务必牢记**）。
3. 打开任意登录页，按 `Ctrl+Shift+F` 体验一键登录。
