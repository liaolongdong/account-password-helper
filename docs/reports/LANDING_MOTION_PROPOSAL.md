## 0. 结论先行

三件事按顺序做，其余都是配菜：

1. **先补地基，再加动效**：本站 `index.html` 的动效层缺三样兄弟站已有的东西——`html.js` 门控、时长令牌、循环动效的视口门控（`is-live`）。其中 `html.js` 门控是**缺陷**：21 个 `.reveal` 节点（含 `#compare` 整节）在没有 JS 时永久 `opacity: 0`。地基不补，后面每加一条动效就多吞一块内容。
2. **只做「让功能自己讲自己」的动效**，不做氛围装饰。最值得做的 4 条：D1 填充流水线跑包（f2）、D2 TOTP 活码倒计时环（f4）、D4 跨子域三档匹配扫描（f14）、D3 安全体检评分计数（f5）。它们的共同点是：动效本身就是产品差异化的说明图，关掉动效这屏就讲不清了。
3. **动效对 SEO 的作用只有一条是硬的**：别把 LCP/CLS 弄坏。想涨曝光，钱要花在元数据、社交预览图、内链与商店文案上（见 §6，本文只交代动效能沾边的部分，不夸大成排名因素）。

**需要点头的只有一处**：B 档（D9 卡片追光、D12 轮播修正、F1 门控）要在落地页新增约 40~60 行内联 JS，这会打破你 2026-09-18 定的「克制专业档 + 纯 CSS、不新增 JS」。A 档完全不碰 JS。

## 6. SEO / 曝光：动效的真实边界

诚实拆开，避免把动效当排名因素卖给你：

- **动效不改变排名**。Google 的排名因素里没有「页面有动画」。
- **动效能碰的三条**：① 核心网页指标不劣化（甚至因 A9 而略好）；② 行为信号（有效停留、滚动深度、`#compare` 是否看完、FAQ 展开率）——这些是观测指标，不是已证实的排名因素，别当 KPI 承诺；③ 外部落地体验：D8 `:target` 回色让搜索/富结果/Blog 跳进来的人一眼确认落点，是这批里唯一「纯 CSS、零成本、直接服务流量入口」的条目。
- **`html.js` 门控（B1）才是这批里唯一有 SEO 硬理由的**：无 JS 抓取路径（部分 AI 爬虫、`Google-Extended` 类）现在读不到对比表和 14 张特性卡的可见文本。
- **同批值得顺手做但不属于动效的**（若你点头可并入）：`llms.txt` 的用例数/文件数与 `sitemap.xml` 的 `lastmod` 是易漂移字段，2026-09-22 实测基准 1337 用例 / 119 文件，落地页当前写作多少需核对；`compare.html`（承接「1Password 替代」「LastPass 替代」这类高意图词）现在零动效零降级，可与 A6 共用资产。

## 7. 落地顺序与验证矩阵

1. **地基**（B1 → B2 → 时长令牌 F3）：先让动效层有 `html.js` 前缀、`--dur-*`、`is-live` 三件东西。
2. **A 档首批**（A1 A4 A3 A6 A7）：每 2 条一次提交，方便回滚定位。
3. **A 档次批 + B3**（视你对 JS 的点头）。
4. **同步产物**：`pnpm gen:en`（`en.html` 是生成物，勿手改）；A 档新增的用户可见装饰文案（如「命中 · 可见」）必须进 `index.html` 的 I18N 字典 `zh` + `en` 两处，纯装饰 `<span>` 用 `aria-hidden="true"`，不用 `content:'→'`（会被朗读且中英不一致）。

### 7.1 减弱动效与无 JS 两行的实测回灌（2026-10-02，两项都已做，方法换了）

上面两行原本写的是「裸 CDP `Emulation.setEmulatedMedia`」和「`--disable-javascript` 截全页」。两条都没按原文执行，因为在本机都量不出可信结果，换了等价方法：

- **减弱动效**：系统 Chrome 154 `--headless=new --force-prefers-reduced-motion --virtual-time-budget=20000 --dump-dom`，页面副本在 `</body>` 前挂一段只读探针（遍历滚动 → 读计算值 → 写进 `<pre id=__probe>`）。
  - **踩到的坑**：`--virtual-time-budget` 推进的是定时器，**不推进动画/过渡时钟**——首轮 41 枚 `.reveal` 全读成 `opacity: 0`，看着像「降级后整页不显形」的致命缺陷，其实是 `getAnimations()` 里那 8 条还停在 `running`。改成先对每条动画调 `finish()` 再读数，才拿到终态。
  - **第二个坑**：同一个 virtual-time 形状下 `window.scrollTo()` 派发不出 IntersectionObserver 回调（真机 Chrome 同页同脚本此前已单独量到 41/41 命中），所以探针在滚动遍历之后把没命中那 40 枚补上 `.visible`，并在输出里带 `ioForcedByProbe: 40` 自证——**这一步把断言范围收窄成「只问 CSS 那一段」**，观察器本身不在此行的判据里。
  - **读数**：`.reveal` 41/41 落 `opacity: 1`、`transform ≠ none` 0 枚；场景表 11/11 行 `opacity: 1`；`getAnimations()` 里 `iterations = Infinity` 的 0 条，剩 8 条全是一次性的 `aph-fade / 200ms / finished`。
  - **停在不可见的那几枚是对的不是错的**：`.cipher-in`（明文，reduce 停在「已加密」那一帧）、闭合态 `.faq-a-inner`、`scrollY = 0` 处的 `.sticky-cta`、被 `display: none` 撤掉的 `.flow-packet` 与 `.carousel-progress`。`.flow-step:nth-child(3)::after` 探针报 MISSING 是量具的限制（`querySelector` 选不到伪元素），不是页面缺节点。
- **无 JS**：**不用** `--disable-javascript`（该开关对本机 headless 的 `--dump-dom` / `--screenshot` 无效，量到的仍是开 JS 的那份）。改为把 index.html 的 `<script>…</script>` 整段剥掉做成副本 `.tmp-rm/nojs.html`，再单独挂探针。
  - **读数**：`html` 上没有 `.js` 类，41/41 枚 `.reveal` 与 11/11 行表格在**开动画**与**减弱动效**两档下都是 `opacity: 1`、0 枚残留位移。也就是 `html.js` 门控那条承诺（隐形初始态只挂在 JS 在场时）成立，爬虫与禁用 JS 用户看到的就是终态。
  - 附带一个不是缺陷的形状：无 JS 时仍有 4 条循环动画在跑（`pulse` / `aph-float` / `aph-sheen` / `aph-bob`），因为这几条没挂 `html.js` 前缀；它们在 reduce 档归零，且没有承载信息的 opacity 变化，所以不影响可读性。

## 8. 风险与未验证项

1. **A9 的 LCP 收益是机制推断，不是实测结论**：`both` + `animation-delay` 会把元素按在 `opacity:0` 的起始帧，全透明期间不作为 LCP 候选；但本站首屏 LCP 元素究竟是 `h1` 文字还是 `.key-card` 渐变块、差多少毫秒，**未测**。没有前后数据就不写进任何对外文案。
2. **A4 依赖 `@property`**（Chrome 85+/Safari 16.4+/Firefox 128+）。不支持时数字必须仍显示终值而不是 0，落地时要把「基准值 = 终值、动画只负责走过去」写清，否则老浏览器出现「82 变 0」的倒退。
3. **A6 用 `td:nth-child(2)` 绑本插件列**：将来表头增删列会静默错位。若接受，就补一条注释；不接受则要给该列加 class（改 30 个单元格，diff 变大）。
4. **D5 的假密文与假凭据**：必须一眼看出是装饰（长度截断 + 等宽 + 灰化），且不能长得像真实凭据格式；同族教训见仓库里旧截图 PII 那次。
5. **B2 会改变轮播既有行为**（减弱动效下不再自动播）。按仓库规则属「影响交互」，需明确确认后再动。
6. **C 档不在本波**：C5/C6 触及秒开 SLA 与换肤一致性，属先方案后实施。
7. lab 页已用 `noindex, nofollow`，且 `docs/prototypes/` 不在 Pages 发布路径内；若要挂到官网需另议。
