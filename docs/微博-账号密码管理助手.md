## 一、头条文章（长贴，首发用）

**标题**：我开源了一个纯本地密码管理 Chrome 插件，专治多环境测试账号混乱

**正文**：
做开发最怕的不是写代码，是"找账号"。
同一个网站，开发/测试/预发各一套账号，普通密码管理器还老填错环境。

于是我自己写了一个：账号密码管理助手（Account Password Helper）。
• 快捷键 Ctrl+Shift+F 一键登录：自动填充 + 勾协议 + 点登录，不只是填充
• 精确域名匹配，dev/test/staging/prod 账号互不混淆
• 内置 TOTP 两步验证，验证码和密码住在一起，告别手机验证器
• 纯本地 AES-256-GCM 加密，零网络传输，无需注册、无订阅
• 从 Chrome/LastPass/Bitwarden/1Password 一键导入，30 秒搬家

完全免费、GPL-3.0 开源、632 项测试兜底。
GitHub：https://github.com/liaolongdong/account-password-helper
在线演示：https://liaolongdong.github.io/account-password-helper/
商店：https://chromewebstore.google.com/detail/account-password-helper/fgimkdodpjfkddmildjieojpfakpanli

## 二、功能短贴（持续发，每条聚焦一个点）

**贴 1 · 一键登录**
别的密码管理器只帮你填表单，登录按钮还得自己点。
我的插件按 Ctrl+Shift+F：填充 → 勾协议 → 点登录，一步到位。
测试同学切环境登录，效率翻倍。
GitHub：https://github.com/liaolongdong/account-password-helper
#效率工具# #测试# #Chrome插件#
（配图：06-sidepanel-fill.png）

**贴 2 · 多环境隔离**
同一站点，dev/test/staging/prod 账号老填错？
精确域名匹配，只展示当前 host 完全一致的账号，localhost 默认放开全部。
联调再也不用"这是哪个环境的密码"。
GitHub：https://github.com/liaolongdong/account-password-helper
#开发者工具# #前端# #测试#
（配图：02-password-list.png）

**贴 3 · 两步验证**
把 TOTP 验证码和密码存在一起。
登录 GitHub 时，插件自动在验证码框旁锚定一个"活码胶囊"，一键填入，不用再掏手机。
本地生成（RFC 6238），零联网。
GitHub：https://github.com/liaolongdong/account-password-helper
#两步验证# #2FA# #安全#
（配图：09-totp-code.png）

**贴 4 · 本地加密/隐私**
无云端、无账号、无订阅。
主密码 PBKDF2 60 万次迭代 + AES-256-GCM，敏感字段全密文，永不上传。
开源可审查（GPL-3.0）。
GitHub：https://github.com/liaolongdong/account-password-helper
#隐私# #本地优先# #开源#
（配图：10-health-check.png）

**贴 5 · 一键迁移**
从 Chrome / LastPass / Bitwarden / 1Password 搬家，30 秒搞定。
CSV/JSON 双格式，自动识别导出格式并映射字段，中英文列名都认。
GitHub：https://github.com/liaolongdong/account-password-helper
#密码管理# #效率#
（配图：03-excel-import.png）
