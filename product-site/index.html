⚡

一键登录，不只是填充

Ctrl/Cmd + Shift + F 一次走完「填账号 → 填密码 → 勾选记住我 / 已阅读并同意 / 接受条款」。再打开「自动触发登录」，或用侧边栏与内联面板里的 「填充并登录」，连登录按钮一起点掉。动态检测登录表单，跨 iframe 也能命中，React / Vue 自建组件与「手机号 + 验证码」场景同样适用。

协议勾选自动识别 · 提交动作独立开关 · 默认不替你点

🎯

多环境账号隔离

默认只认完全一致的主机名： dev-admin.example.com 的账号绝不会出现在 admin.example.com 的候选里。在 localhost / 127.0.0.1 上还进一步按端口区分。开发者与测试的刚需，也是它最常被提起的一条差异。

三档跨子域匹配可按需放宽 → 见下方模拟器

🔑

内置 TOTP + 两步登录接力

验证码密钥和密码存在一起（RFC 6238，本地生成），列表与侧边栏直接显示 6 位活码和倒计时圆环。遇到 GitHub 式两步登录，跳到验证码页后活码胶囊会 自动锚定，点「填入」完成第二步——不用切 App、不用摸手机。

支持扫码 / 上传图片本地解码 · 6/7/8 位与算法可自定义

🧲

填不进的页面有兜底

自动检测拿不准的自建登录页（典型是 Web Components 站点），可在管理页「站点规则」为该域名指定账号 / 密码框的 CSS 选择器，每条规则默认开启 影子 DOM 穿透。规则还能导出成明文 JSON（只含域名与选择器，不含账号密码），按域名合并导入、回报新增 / 更新 / 忽略，换机或团队共用不必逐条手配。

封闭 Shadow DOM（mode: closed）任何扩展都读不到，这是浏览器边界

🔒

纯本地加密，零云端

主密码经 PBKDF2-SHA256（600,000 次迭代）派生密钥，五个敏感字段逐个用 AES-256-GCM 加密、每次新的随机 IV，明文只存在于扩展自身上下文。锁定或过期只销毁密钥材料与内存快照——磁盘上本来就是密文，所以 不会在过期瞬间批量重加密，也就没有卡顿。

不使用 storage.sync / managed · 主密码任何形态都不落盘

📊

离线安全体检

一键给出 0–100 分综合评分，四维加权：账号复用 35、弱密码 25、命中泄露字典 20、长期未更新 20；「未开启两步验证」单独列示、不计入扣分。泄露字典是内置近千条的离线词表，全程不联网、不上传任何条目。

可按条目设 7 / 30 / 90 天改密提醒，到期发桌面通知

📦

一键迁移，零门槛

导入时自动识别 Chrome、LastPass、Bitwarden、1Password 的导出格式，CSV / JSON 双格式、中英文列名自动映射，30 秒搬家。反向也有：加密备份（.aph）导出导入支持解密预览，邮箱备份在本机组好内容后经 mailto: 交给你自己的邮件客户端发送。

条目上限 2000，回收站不占额度 · 接近上限时列表按页渲染

开发者 隔离多环境账号，同一站点的 dev / test / staging / prod 互不串号；测试工程师 一键填充 + 自动触发登录，跨环境回归少摸十倍键盘； 隐私敏感用户 纯本地加密、无需注册与云端同步；日常用户 告别记忆密码，内置 TOTP 与密码生成器。

01

🔒 安全防护

加密、会话、锁定与体检

  • 本地强加密 · 主密码 PBKDF2-SHA256 600,000 次迭代派生密钥；用户名 / 密码 / 网址 / 备注 / TOTP 密钥五个敏感字段逐字段 AES-256-GCM，每次新的随机 IV
  • 会话可控 · 有效期 1 小时至 7 天可选（默认 24 小时），剩余时间在管理页 / 侧边栏 / Popup 常驻展示，临近过期变色预警，点徽标即可续期
  • 自动锁定与剪贴板 · 复制敏感字段后默认 30 秒清除剪贴板；闲置自动锁定与「浏览器重启锁定」默认关闭，可独立开启
  • 离线安全体检 · 0–100 四维加权评分，未开启 2FA 仅列示不计分，全程不联网
  • 到期提醒 · 在「长时间未更新」明细中按条目设 7 / 30 / 90 天改密提醒，到期发桌面通知
  • TOTP 两步验证 · 本地生成（RFC 6238），列表与侧边栏实时活码与倒计时，GitHub 式两步登录自动衔接活码胶囊

⚡ 智能填充

入口、匹配规则与保存

  • 一键登录 · 填充账号密码 + 自动勾选「记住我 / 已阅读并同意 / 接受条款」；开启「自动触发登录」或使用「填充并登录」后连登录按钮一起点
  • 四种填充入口 · 页内面板（默认）、侧边栏一键填充、输入框右键、快捷键；动态检测登录表单含跨 iframe，兼容 React / Vue 与手机号 + 验证码场景
  • 页内面板即开即填 · 与侧边栏同一套排序和检索口径（用户名 / 标签 / 备注 / 网址多字段，认拼音全拼与首字母缩写），打开与每次筛选后默认选中首条、回车直接填充；中文输入法尚未上屏时不接管 ↑↓ / Enter / Esc
  • 站点规则兜底 · 为域名指定账号 / 密码框的自定义 CSS 选择器，默认开启影子 DOM 穿透，规则可导出明文 JSON 按域名合并导入
  • 自动保存凭证 · Chrome 式登录捕获与保存确认，相同凭证不重复提示、密码变化弹「更新」确认；支持域名黑白名单与「不再提示」，弹窗内联提示弱密码与复用风险
  • 精确域名匹配 · 所有填充入口与列表默认只展示与当前 host 完全一致的条目；跨子域匹配提供三档按需放宽，localhost 始终按端口隔离
  • 就地添加与全站搜索 · 侧边栏顶栏「+」预填当前域名快速建档；搜索一键切换「本站 / 全站」范围，外站命中仍可复制账号密码验证码、收藏与编辑
  • 分享卡片 · 一次点击把「用户名 / 密码 / 网址」合成一段纯文本复制进剪贴板，同受限时自动清除约束，内容只写本机剪贴板、不发起任何网络请求

📦 数据管理

迁移、组织与防误操作

  • 导入导出 · CSV / JSON 双格式，自动识别 Chrome、LastPass、Bitwarden、1Password 的导出格式，中英文列名自动映射（Excel 请先另存为 CSV）
  • 多重备份 · 加密备份（.aph）导出 / 导入支持解密预览；邮箱备份本机组好内容后经 mailto: 交由你的邮件客户端发送；定时备份提醒只发桌面通知，不会自动发信
  • 高效组织 · 标签多选与筛选、收藏置顶（默认上限 10 条，可配 1–50，超出按 LRU 淘汰）、拼音 / 首字母智能搜索与高亮、一键去重、批量删除 / 改标签 / 导出选中
  • 列表分页 · 默认每页 100 条（可切 50 / 100 / 200，档位记在本机），一次只渲染当前页；跨页勾选保留，新增 / 编辑 / 收藏后自动跳到该条所在页并高亮
  • 防误操作 · 回收站 30 天软删除（按最近删除排在最前，可按关键词检索）；密码修改历史默认保留 3 份加密快照（可配 1–10）且可恢复；修改主密码原子换钥不丢数据
  • 身份信息库 · 独立的个人信息收藏夹（姓名 / 证件号 / 手机号 / 邮箱 / 住址 / 银行卡与自定义字段），默认掩码、打开需主密码复验，支持加密备份（.aphid）

How it works

一次填充，在你自己的电脑上走四步

没有服务器参与任何一步。四步全部发生在本机：内容脚本判定字段、按域名取候选、扩展上下文内解密、逐字段写入。

STEP 1

识别登录页

内容脚本在页面里判定账号、密码与验证码输入框；扫描限流分批进行， 注入式 UI 走 Closed Shadow DOM，不改动宿主页面的样式与脚本。

MutationObserver 收窄 + 分批
STEP 2

按域名取候选

三档跨子域匹配决定哪些账号出现在侧边栏与内联下拉里。默认只认精确主机名， 多环境账号因此互不串号。

resolveMatchTier(三档)
STEP 3

本机解密

主密码经 PBKDF2 派生密钥，打开列表时整库解密一次。明文只存在于扩展自身上下文， 磁盘上始终是密文；锁定或过期即刻销毁密钥材料与快照。

storage.session 存密钥
STEP 4

填充并登录

逐字段写入并自动勾选「记住我 / 同意协议」，可选再替你点下登录按钮； 网页上新产生的凭证回写前，先经你确认。

Privacy by construction

「没有云端」不是一个营销词，
它是一串可核对的约束

下面每一条都能在源码或扩展的权限清单里对上号。这个项目的两条硬约束是 密码数据不出本机与权限最小化。

🗄数据在哪里

  • ·条目保存在 chrome.storage.local，敏感字段逐字段加密后落盘，从不作为明文离开本机
  • ·内存态密钥与解密快照只放在 chrome.storage.session，不使用 storage.sync 或 storage.managed
  • ·主密码任何形态（原文、可逆密文）都不落盘，仅保存 PBKDF2 派生的校验值；主密码遗忘无法找回，只能重置清空数据
  • ·锁定与过期只销毁密钥材料，磁盘上本来就是密文，因此不存在「过期瞬间整库重新加密」这一步

📡唯一的对外请求

  • ·每 6 小时一次的匿名版本检查：商店安装版向商店条目页发一个不透明的 HEAD 请求，手动安装版查询 GitHub Releases 的公开版本信息
  • ·两者都不携带任何密码库内容、账号、标识符或可推导信息；断网时静默失败，不影响任何核心功能
  • ·网站图标读取 Chrome 本地缓存（_favicon/ 端点），零外部网络请求
  • ·除此之外不发起任何外部网络请求，离线可用

🚫明确不做

  • ✕不读取 cookies、history、downloads 等未声明权限
  • ✕无遥测、分析、广告与崩溃上报 SDK，不收集设备指纹或使用统计
  • ✕不记录、不上传主密码、账号、密码、TOTP secret 或解密后的条目
  • ✕不自行发明加密方案：用 Web Crypto 与既有封装，无固定 IV、无弱化迭代参数

Get started

四步上手，日常用不到一张快捷键表

安装后不需要注册、不需要登录任何账号。第一次进管理页设主密码，之后就是「看到登录框 → 选账号 → 填进去」。

1

设置主密码

首次进入管理页设置主密码（至少 8 位，含字母 + 数字 + 特殊字符）并选择会话有效期，默认 24 小时。

2

挑一种填充方式

全新安装默认内联填充——登录框获焦后点钥匙图标选账号；可在「偏好设置」切为侧边栏（获焦自动弹出）或仅手动。升级用户沿用升级前的侧边栏行为，不会被静默改为内联。

3

导入已有密码

管理页「数据管理 → 导入」上传 CSV / JSON，自动识别 Chrome、LastPass、Bitwarden、1Password 的导出格式并映射字段。

4

按需开启自动登录

「偏好设置 → 自动触发登录」打开后，Ctrl+Shift+F 连登录按钮一起点掉；不开就停在「已填充 + 已勾选」。

FAQ

最常被问到的九件事

我的密码会被上传到云端吗？

不会。数据只保存在浏览器本地空间，敏感字段逐字段加密后落盘。唯一的外联是每 6 小时一次的匿名版本检查，不携带任何可推导信息。除此之外不发起任何外部网络请求，网站图标也来自 Chrome 本地缓存。

忘记主密码怎么办？

主密码无法找回，只能通过「重置」清空数据后重新设置。 这不是产品缺陷，而是「没有服务器可以帮你重置」的直接代价——同一个设计保证了别人也无法替你重置。 请务必定期用数据导出或加密备份（.aph 文件）留退路。

会话有效期到了会发生什么？

会话过期只清除密钥材料与内存缓存。磁盘上的敏感字段本来就是密文，不存在「过期瞬间批量重新加密」这一步，因此不会卡顿。 下次使用时重新验证主密码即可恢复访问，账号数据不会丢失。

支持从其他密码管理器导入吗？

支持。在导入弹窗上传 CSV 或 JSON 文件，插件会自动识别 Chrome、LastPass、Bitwarden、1Password 的导出格式并映射字段，30 秒完成搬家。Excel 需先另存为 CSV（不解析 .xlsx）。

同一套账号要覆盖整个站点的子域名，怎么办？

管理页头部的「跨子域名匹配」提供三档，默认是「仅精确匹配」。切到「精确 + 通配条目」后，网址写成 *.qq.com 的账号会在该站任意子域出现；切到「同主域名」再加一层兜底——当前域名没有账号时依次带出主域与兄弟子域的条目，并在列表里标注「跨子域」。

放宽只改变哪些账号被展示与可填充：自动保存的判重口径不随档位改变，localhost / 127.0.0.1 始终按端口区分，侧边栏与内联下拉共用同一套排序、一键填充取首条。上面那个模拟器就是在跑这套规则。

登录框识别不到，或者填不进去怎么办？

表单藏在自建组件里时（典型是 Web Components 页面），在管理页「站点规则」为该域名手动指定账号与密码输入框的 CSS 选择器即可——域名需与登录页完全一致，不支持通配。每条规则默认开启「影子 DOM 穿透」，可关闭以只在主文档内匹配。

需要说明的边界：任何扩展都读不到 mode: 'closed' 的封闭 Shadow DOM，只能进入开放的 Shadow DOM——这是浏览器给的限制，不是实现问题。

导出的 CSV 用 Excel 打开，个别密码或备注变成了报错内容？

当某个字段的值本身以 =、+、-、@ 开头（随机密码生成器的符号集就含这几个字符）时，Excel 会把该单元格当作公式求值。导出刻意不做公式转义：加前缀会改写字段内容，而密码是逐字符取用的，被改写后无论是从表格复制使用还是再导回来都是错的，同时也会破坏「导出 → 导入」的可逆性。

请把导出文件视为你自己本机产出的数据，跨机迁移优先使用加密备份（.aph）。

条目数量有上限吗？接近上限时管理页会卡吗？

有。密码列表条目总量上限为 2000 条，按列表条目数计数，回收站里的条目不占额度。达到上限后新增、导入、网页自动保存与回收站恢复都会明确提示被拒绝，不会静默覆盖或删除已保存的数据。

列表按页呈现（默认每页 100 条，可切 50 / 100 / 200），一次只渲染当前这一页，所以搜索、输入过滤、翻页、悬停这类交互的耗时基本不再随条目数增长。打开管理页还包含一次「读整库并解密」，这一步的开销与条目总数相关、不由分页决定——这里的口径是「成本不随行数逐条放大」，不是「恒定耗时」。

侧边栏不显示，或首次打开较慢？

侧边栏依赖 Chrome 的 Side Panel API（需 Chromium 114 及以上），也可点击插件图标或按 Ctrl+Shift+L 打开。Windows 上首次冷启动可能因 Defender 逐文件扫描延迟 1–2 秒，把扩展目录加入排除列表即可降到 1 秒以内（Mac 无需操作）。

会话有效期内保持常驻，侧边栏走缓存快路径，数据在 20–50ms 内返回。
