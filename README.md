# Account Password Helper - 账号密码管理助手

一个功能强大的Chrome浏览器插件，用于自动管理和填充网站账号密码。

## 🚀 功能特性

### 核心功能

- ✅ **安全密码管理**：使用MD5加密保护主密码，确保数据安全
- ✅ **智能表单检测**：自动检测网页中的登录表单
- ✅ **一键密码填充**：点击侧边栏中的密码条目即可自动填充
- ✅ **自动勾选复选框**：填充密码后自动勾选最近的复选框（如"记住我"）
- ✅ **灵活URL匹配**：支持精确URL匹配或全局匹配
- ✅ **拖拽排序**：支持密码条目的拖拽排序
- ✅ **Excel导入导出**：支持批量导入和导出密码数据
- ✅ **批量操作**：支持批量删除密码条目
- ✅ **快捷键支持**：支持快捷键快速打开选项页面和侧边栏
- ✅ **密码复制**：支持快速复制现有密码条目创建新条目

### 安全特性

- 🔒 **主密码保护**：首次使用需设置主密码
- 🔒 **密码验证**：查看密码和导出数据需验证主密码
- 🔒 **本地存储**：所有数据存储在浏览器本地，不上传到服务器
- 🔒 **权限最小化**：遵循最小权限原则，只申请必要权限

## 📦 技术栈

- **框架**：WXT + Vue3 + TypeScript
- **UI组件**：Element Plus
- **构建工具**：Vite
- **加密**：crypto-js (MD5)
- **Excel处理**：xlsx

## 🛠️ 安装使用

### 开发环境安装

1. **克隆项目**

```bash
git clone <repository-url>
cd account-password-helper
```

2. **安装依赖**

```bash
npm install
```

3. **开发模式运行**

```bash
npm run dev
```

4. **构建生产版本**

```bash
npm run build
```

### Chrome浏览器安装

1. **构建插件**

```bash
npm run build
```

2. **加载插件**
   - 打开Chrome浏览器
   - 访问 `chrome://extensions/`
   - 开启"开发者模式"
   - 点击"加载已解压的扩展程序"
   - 选择 `.output/chrome-mv3` 文件夹

3. **首次设置**
   - 点击插件图标，进入设置页面
   - 设置主密码（请务必记住此密码）
   - 开始添加账号密码

## 📋 使用指南

### 1. 设置主密码

首次使用时，插件会要求设置主密码。此密码用于保护所有账号信息，请务必妥善保管。

### 2. 添加密码

1. 点击插件图标
2. 点击"管理密码"进入设置页面
3. 点击"添加密码"按钮
4. 填写相关信息：
   - **用户名**（必填）：账号或邮箱
   - **密码**（必填）：登录密码
   - **URL**（选填）：不填则匹配所有网站
   - **标签**（选填）：如"工作"、"个人"等
   - **备注**（选填）：备注信息

### 3. 自动填充密码

1. 在登录页面点击用户名或密码输入框
2. 侧边栏会自动打开并显示匹配的密码
3. 点击对应的密码条目即可自动填充
4. 插件会自动勾选最近的复选框（如"记住我"）

### 4. 快捷键操作

插件支持以下快捷键操作：

- **Ctrl+Shift+P** (Mac: Cmd+Shift+P)：打开密码管理选项页面
- **Ctrl+Shift+L** (Mac: Cmd+Shift+L)：打开/关闭密码快速填充侧边栏

注意：快捷键可以在Chrome扩展管理页面中进行自定义。

### 5. 密码复制功能

在密码管理页面的操作列中，新增了"复制"按钮。点击该按钮可以快速创建一个与当前密码条目内容相同的新条目，并插入到当前条目的下方。这在需要为相似账户创建密码时非常有用。

### 6. 密码管理

- **编辑**：在设置页面点击"编辑"按钮
- **删除**：点击"删除"按钮或批量选择删除
- **排序**：支持按字段倒序或者正序进行排序
- **搜索**：使用搜索框快速查找密码

### 7. 导入导出

- **导出**：点击"导出Excel"按钮将密码导出为Excel文件
- **导入**：点击"导入Excel"选择Excel文件批量导入
- **模板**：点击"下载模板"获取标准Excel格式

## 📊 Excel格式说明

### 导入支持的列名

- **用户名**：username/Username/用户名/账号
- **密码**：password/Password/密码
- **URL**：url/URL/网址/链接
- **标签**：tag/Tag/标签/分类
- **备注**：remark/Remark/备注/说明

### 示例格式

| 用户名           | 密码        | URL                 | 标签 | 备注     |
| ---------------- | ----------- | ------------------- | ---- | -------- |

## 🆘 常见问题

### Q: 忘记主密码怎么办？

A: 主密码无法找回，只能清空所有数据重新开始。建议定期备份密码数据。

### Q: 为什么侧边栏不显示？

A: 请确保Chrome版本支持sidePanel API（Chrome 114+），且插件已正确安装。

### Q: Excel导入失败怎么办？

A: 请检查Excel文件格式是否正确，确保包含"用户名"和"密码"列。

### Q: 密码填充不生效？

A: 请确保网页已完全加载，某些动态加载的表单可能需要刷新页面。

### Q: 快捷键不生效怎么办？

A: 请检查快捷键是否与其他扩展冲突，可以在Chrome扩展管理页面中修改快捷键设置。
