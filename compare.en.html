Frequently asked questions

Is there a free password manager better than Bitwarden?

If you value zero-cloud, no sign-up and fully local storage, Account Password Helper is a Bitwarden alternative: free and open source (GPL-3.0), no account, no sync, data encrypted locally by PBKDF2 + AES-256-GCM. For cross-device sync and mobile, Bitwarden is still the better fit.

Is there a free alternative to 1Password?

Yes. Account Password Helper is subscription-free and account-free, with local encryption, one-keystroke login, built-in TOTP and a security audit all free. 1Password's strengths are cross-platform polish and team / family collaboration.

Difference between Chrome's built-in manager and an extension?

Chrome's built-in manager is free and needs no install, but only fills forms — no multi-environment isolation, no TOTP generation, no offline audit, no encrypted backup. This extension adds those and supports one-keystroke login.

Is a local password manager safe?

It uses the browser-native Web Crypto API: the master password is derived via PBKDF2 (600,000 iterations) and fields are authenticated-encrypted with AES-256-GCM, with zero network transfer. A forgotten master password can't be recovered, so keep encrypted backups; as with any extension, avoid banking / payment credentials.
